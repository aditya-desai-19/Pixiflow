
# Pixiflow: An alternative to applications like Image Resizer, Reduce Images etc.

## Motivation

I'm learning Spring Boot. To apply my knowledge I have created this project.

## Features

* Resize images to any custom height and width.
* View and manage previously resized images.
* Resize images using two methods by exact dimensions or by percentage.

## Tech Stack

* Spring Boot with Java (Backend framework)
* OpenCV Java Sdk
* AWS S3 service and AWS Java Sdk
* Postgresql (Database)
* Openapi spec (Documentation and Api design)
* Next.js (Frontend framework)
* shadcn ui (UI Library)
* Tailwind CSS
